# House Price Prediction

This project predicts house prices using machine learning regression models.  
The dataset was cleaned and prepared before training the models.  
Feature preprocessing and basic feature engineering were applied.  
Multiple regression approaches were tested to improve prediction performance.  
Models were trained and evaluated using Scikit-learn.  
Performance was measured using standard regression metrics.  
The project demonstrates a complete workflow from data preprocessing to model evaluation.  
Implemented in Python using common data science libraries.

Data source:
