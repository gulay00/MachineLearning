Country Data Clustering

This project analyzes a country-level dataset using KMeans clustering to group countries based on numeric indicators like child mortality, income, GDP, life expectancy, and more.

Features

Exploratory Data Analysis (EDA): histograms, scatter plots, and correlation heatmaps

Clustering: KMeans applied on numeric features

Visualization: Scatter plots showing cluster assignments

Insight: Identify patterns and similarities between countries

Usage

Load the dataset (CSV or DataFrame).

Select numeric columns for clustering.

Apply KMeans and assign cluster labels.

Visualize clusters using scatter plots or hexbin plots.

Requirements

Python 3.x

pandas

matplotlib

seaborn

scikit-learn
